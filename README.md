# Stuff

## Vector Space — Field Laboratory

[Download vector-space.zip](https://github.com/juhaochen387-cmyk/Stuff/raw/refs/heads/main/vector-space.zip)

Extract the ZIP and open `vector-space/index.html` for the self-contained, offline vector-field app. It includes Wolfram-style numerical preview, interactive 3D streamlines, approximate null detection, point diagnostics and a curved-ray view with an explicitly stated bending model.

For arbitrary Wolfram Language definitions, run the included local Python bridge with an activated Wolfram Engine or Mathematica installation. **No API key is needed.** See the README inside the ZIP for setup, mathematical assumptions, references, examples and validation limits.

The renderer distinguishes Euclidean streamline curvature and its chosen field-to-ray connection from four-dimensional metric-based null geodesics. Both supplied references are discussed in the app guide.
